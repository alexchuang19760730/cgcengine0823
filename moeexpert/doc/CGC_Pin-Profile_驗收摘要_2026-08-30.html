一、八維度品質判定

✅ = 優 · ⚠️ = 需注意 · ➖ = 中性
維度判定依據
路由質量涵蓋✅ 優coverage mean=87.8%（min 80.8 / max 93.1）；uniform baseline ≈34% → 2.6× 重尾確證
位元級安全（exact 模式）✅ 優pin 只改 placement 不改 bytes；開/關輸出位元級相同（T-PN3 實證）
fast-path 品質影響⚠️ 條件性VERIFY/DRAFT cold 讀 ZERO slot 時，pin 減少 cold = 品質提升（正向副作用）
死鎖 / NaN 安全✅ 優槽滿時 pass-2 靜態 pin 讓位（記 pin_yield）—— 不卡死、不留 table==-1
workload 特異性⚠️ 最大弱點跨配置 top-K 重疊僅 ~29% —— 換 workload 必須重校準，否則保護錯的「熱」集
硬體 K 耦合⚠️ 需注意K = f(cache bytes, LAYER_CAPS)；大 cache 產的 profile 拿到小 cache 機器 pin 密度稀釋，反向覆蓋不足
模型錯配防護⚠️ 僅範圍檢查id 只驗 [0, n_expert) —— 錯模型 id 在範圍內靜默接受；靠檔名綁模型紀律
懶標記➖ 中性expert 首次被路由填入才 pin → 載入零成本，前幾個 step 漸生效

結論

Pin profile 的核心承諾已實證：exact 模式下開/關位元級一致（T-PN3），placement 槓桿有效（coverage 2.6× baseline，T-PN5），機制無死鎖風險（pass-2 讓位）。
主要風險不在正確性而在時效性：profile 是 workload 快照（特異性 ~29% 重疊），換模型/硬體/workload 不重校準 = 靜默保護錯誤的熱集 —— 已納入測試計劃 §9 場景表（換環境 → 重校準 ~5 分鐘）與 §10 排查表（T-PN1~5 症狀 → 動作）。
