TPOT / 驗收判讀

這次 commit 的核心是 deploy 驗收自動化，不是新的 decode kernel 優化，因此不應把它解讀成新的 TPOT 提升刀。TPOT 應以最近一次 verify-side 穩定量測為基準；本次要鎖定的是：

  • 最新 HEAD 的 macOS bundle 可以從 deploy-harmonyos 重新生成。
  • 重建後的 llama-server / llama-simple 能啟動，且版本號對上目前核心 commit。
  • 這套驗收能進 precommit，在需要時成為正式 gate。

建議

  • 日常 commit 維持預設關閉 deploy 重型驗收，避免每次 precommit 都做完整 bundle rebuild。
  • 發佈前或切給 deploy-harmonyos 前，固定用 RUN_DEPLOY_HARMONYOS_ACCEPT=1 跑一遍。
  • 若要在 deploy 報告中引入新的 TPOT 數字，應在同一 commit 後重新跑 production shell，再補量測段落。
