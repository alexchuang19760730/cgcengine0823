Write a concise C++ implementation of a thread-safe LRU cache with a bounded byte budget, using a hash map for lookups, a doubly linked list for recency ordering, and a mutex protecting all mutations. The cache should support get, put, and a size limit; when the limit is exceeded, the least recently used entry is evicted. Explain the time complexity of each operation and how the linked-list nodes are pooled to avoid per-operation heap allocation. Then describe how you would extend it to a sharded design with striped locks to improve throughput on many-core machines, and how to test it with a concurrent stress harness that detects race conditions under TSan.
