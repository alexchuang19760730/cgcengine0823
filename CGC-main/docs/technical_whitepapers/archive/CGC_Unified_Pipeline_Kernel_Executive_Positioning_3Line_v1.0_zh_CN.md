# CGC Unified Pipeline Kernel 对外 3 句式定位文案 v1.0

## 标准文案

`CGC Unified Pipeline Kernel` 是一套面向企业 `agent / model / embodied` 三类任务实体的统一采集、训练、推理与端云交付内核，而不是单一训练框架、单一推理框架或单一 MLOps 编排层。  
它通过统一的 `ExecutionContext`、`State ABI`、`publish_manifest`、`runtime_contract` 与 `matrix_axes`，把多框架训练、多框架权重交付、多环境推理与多硬件部署收敛到同一个可编排、可比较、可审计、可交付的执行主干之下。  
在具身场景中，这套内核进一步通过 `bridge artifact + edge-cloud protocol + edge runner / runtime host`，把训练得到的模型能力正式发布到端侧 CGC engine 执行，形成从训练到端侧推理与 comparative evidence 的完整闭环。
