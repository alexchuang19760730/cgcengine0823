2. 四大核心模块

⚡ MoE Engine Core

MoE 模型推理加速引擎，专为 35B-A3B 等稀疏 MoE 模型优化

  • Expert Cache — 4GiB 预加载池，Mac M4: 3→27 t/s (9x)
  • L4 Skip Load — 跳过非活跃 expert 磁盘读取
  • Expert Prefetch — hist/src 双模式预测性加载
  • GLU Fused Down — 融合 gate+up 计算

✅ 已验证 Expert Cache + L4 Skip

🚀 General Engine MTP

通用推理加速，MTP Speculative Decoding + PD 分离

  • MTP Draft × 2-4 — 一次预测多 token，加速 50-100%
  • PD Separation — Prefill-Decode 分离，跨设备推理
  • DOPD Router — Decode-Speed 感知路由
  • edge_server.py — 设备级 HTTP endpoint

✅ 已验证 MTP 26.4 t/s / accept 97.4%

🧠 Agent Harness Agent

智能体框架，DSH + Prime Agent 自改进循环

  • DSH — 插件化 agent harness (v0.1.2)
  • Prime Agent — RLM 递归子代理 + /refine
  • Terminal-Bench — 76 任务评估套件
  • SFT Pipeline — 轨迹→数据集→LoRA 微调

🔧 开发中 Phase 1: DSH Baseline

🔀 Hermes Router Router

多维路由决策，4D 评分 + decode-speed 感知

  • 4D Routing — RAM/GPU/Score/Speed 综合评分
  • Decode-Speed — 实测 tok/s 驱动决策
  • DeviceProfile — 设备能力自动上报
  • PD Modes — pure_cloud/edge_cloud/local_full

✅ 已验证 Windows↔Mac 联调通过
