0. Executive Summary

一句话结论： FusionRoute+MoT 不只是"更好的 Router"，而是"完整的推理调度系统"。它用 token-level 路由 + 系统感知取代 Hermes，用零延迟特征收集取代 4D Matrix，用 4 步并行 + 自动容错取代 10-Step Pipeline。

🎯 替代 Hermes

Token-level 路由 + FeatureSchema，零延迟（<1ms vs LLM 推理延迟），确定性输出。

⚡ 替代 4D Matrix

PerceptionLayer 实时采集 Network/Hardware/Model/Runtime 四维特征，无需 LLM 建议。

🔄 替代 10-Step

4 步并行 + 自动 ROI 门控 + P2P 自动发现，更快、更简单、自动恢复。

3. 六阶段实施计划

Phase 1: 4D 感知层 (Week 1-2)

P0 目标：让 Router 看到系统状态

扩展 FeatureSchema，加入实时系统指标。每个 edge_server 上报 DeviceProfile。Router 输入从 [hidden_state] 变为 [hidden_state + feature_vector]。

做什么

  • 实现 PerceptionLayer 类
  • 收集 D1-D4 四维特征
  • 每次路由决策附带完整特征向量

验收标准

  • FeatureSchema 包含 4D 所有维度
  • 特征采集延迟 < 1ms
  • 特征向量可序列化为 JSON
# 新增: src/fusion_route/perception.py
class PerceptionLayer:
    def collect_features(self) -> FeatureSchema:
        return FeatureSchema(
            # D1: Network
            network_rtt_ms=self.measure_rtt(),
            bandwidth_mbps=self.measure_bandwidth(),
            # D2: Hardware
            total_ram_gb=psutil.virtual_memory().total / 1e9,
            available_ram_gb=psutil.virtual_memory().available / 1e9,
            gpu_vram_gb=self.get_gpu_vram(),
            cpu_load_pct=psutil.cpu_percent(),
            # D3: Model
            model_params_b=self.model.params,
            is_moe=self.model.is_moe,
            has_mtp=self.model.has_mtp,
            # D4: Runtime
            memory_pressure=self.get_memory_pressure(),
            expert_hit_rate=self.expert_cache.hit_rate,
            accept_rate_ema=self.mtp.accept_rate,
        )

Phase 4: Speculation ROI 门控 (Week 7-8)

P1 目标：让 speculation "earn its keep"

跟踪 accept rate、draft cost、verify cost。计算 ROI。ROI < 0 时自动关闭 speculation。

# SpeculationGuard 核心逻辑
class SpeculationGuard:
    def should_speculate(self) -> bool:
        if self.roi_ema < 0:
            return False  # speculation 亏本，关闭
        if self.accept_rate_ema < 0.5:
            return False  # accept rate 太低
        return True
    
    def get_draft_depth(self) -> int:
        if self.roi_ema > 2.0:
            return 4  # 高 ROI，激进 draft
        elif self.roi_ema > 0.5:
            return 2  # 中等 ROI，保守 draft
        else:
            return 0  # 低 ROI，关闭

4. 与 Hermes/4D/10-Step 对比

4.1 vs Hermes Router

❌ Hermes Router

  • Query-level 路由（整 query 选一个模型）
  • 静态 FeatureSchema（model_size, RTT, TFLOPS）
  • SFT on rules（学习硬编码规则）
  • 无 KV 管理
  • 固定 speculation 策略

✅ FusionRoute v2

  • Token-level 路由（每个 token 独立选择）
  • 动态 FeatureSchema + hidden state
  • CDPO on real metrics（学习真实系统状态）
  • KV Translation（O(n) 线性映射）
  • 动态 ROI 门控（自动开关 speculation）

4.2 vs 4D Perception Matrix

❌ 4D Perception Matrix

  • LLM 参与决策（建议器）
  • 需要额外 LLM 推理延迟
  • LLM 输出不确定（需契约投影）
  • 高成本（每次推理都要 LLM）

✅ FusionRoute v2 PerceptionLayer

  • 确定性特征收集（无 LLM）
  • 零延迟（<1ms，纯系统调用）
  • 可验证输出（Router 直接决策）
  • 零额外成本

4.3 vs 10-Step Pipeline

❌ 10-Step Pipeline

  • 10 步串行（慢）
  • 静态规则调度
  • 手动 fallback
  • 加节点需改配置

✅ FusionRoute v2

  • 4 步并行（快）
  • 动态 Router（实时决策）
  • 自动 ROI 门控（自动恢复）
  • P2P 自动发现（零配置）
